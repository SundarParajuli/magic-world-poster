Changelog

Notable changes to Magic World Poster.

1.2 — November 2026

  • Added a unified queue status view that shows Facebook, Instagram and TikTok results side by side.
  • Improved TikTok inbox-draft handling, including a clear retry state when the draft limit is reached.
  • Added AI-generated content disclosure support for platforms that accept a disclosure flag.
  • Expanded the FAQ, user guide and support pages.

1.1 — October 2026

  • Added per-platform retry with backoff and partial-success reporting.
  • Added caption fingerprints and stored post identifiers to prevent duplicate publishing after a restart.
  • Added local logging with token redaction.

1.0 — October 2026

  • First release: local video queue, scheduling, Facebook Page and Instagram Reels publishing, and TikTok Content Posting API integration.
  • Added the review-and-confirm publish wizard, including TikTok privacy selection.

Website

  • 2 November 2026 — Added the features, how-it-works, user guide, FAQ, support and changelog pages; introduced the app icon as the site logo and favicon.
  • 18 October 2026 — Initial product and legal pages.
