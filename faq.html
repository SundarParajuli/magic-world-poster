Frequently asked questions

Answers about accounts, publishing, data and troubleshooting.

What is Magic World Poster?

It is a desktop application that keeps a queue of short-form videos and publishes them to Facebook Pages, Instagram professional accounts and TikTok accounts that you are authorized to manage. It uses the platforms' official APIs and records the result of every post.

Is this a website or a desktop app?

It is a desktop app. This website is the product documentation and support site. You install and run the app on your own computer; there is no cloud account to create.

Does the app publish without my confirmation?

No. You build the queue and choose when each item is due. TikTok publishing requires you to review the post, choose a privacy status and explicitly confirm consent. Facebook and Instagram posts follow the schedule you set.

Which TikTok permissions does it use?

The app requests user.info.basic to show the connected account, video.publish to publish an approved video, and video.upload to send a draft to the TikTok inbox. These are used only for the publishing features described on this site.

Why does my TikTok video arrive as a draft?

TikTok's API only allows direct publishing for apps with the appropriate approved access. When direct publish is not available, the app places the video in your TikTok inbox. You finish the post in TikTok, and the app marks the item as a draft so you know it needs attention.

Can I publish to several platforms at once?

Yes. Set the destinations for an item to any combination of Facebook, Instagram and TikTok. Each platform is tracked separately, so a failure on one does not cause an already-successful post on another to be repeated.

Where are my videos and tokens stored?

On the machine where the app runs, in its local data folder. Videos are transmitted only to the platform you select when a post is published. Tokens are kept out of the public source code and out of ordinary log output. See the Privacy Policy.

How do I delete my data?

Remove individual items in the app to delete their local records and video copies. To remove all information held by the app, follow the instructions on the data deletion page. Data already sent to a platform is governed by that platform's own controls.

What happens if the app is closed at the scheduled time?

Overdue items are caught up when the app starts again, in queue order. You do not need to re-add or reschedule them.

Does it work on Windows, macOS and Linux?

The app is a Python desktop application and runs wherever Python 3.10+ with Tk and Pillow are available. The publishing workflow is the same on each platform.

How do I get help?

Use the support page. Include the platform, the affected item's status and the error text so the issue can be reproduced quickly.
